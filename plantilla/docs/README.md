# `docs/` — la doc de ESTA instalación

Lo que es verdad aquí y no en el producto: qué se instaló, cuándo, con qué decisiones propias y qué tiene
esta instalación que no tienen las demás.

⚠️ **Las decisiones de una instancia llevan su propio prefijo** (`PJP-1`, `PJP-2`…) y **nunca un número del
producto**: los del producto salen de las bandas de sus carriles, y dos registros que se numeren igual se
confunden en cuanto alguien cite «la 12».

⚠️ Lo que valga para TODAS las instalaciones no se escribe aquí: eso es producto, y su sitio es la doc del
producto. Si al escribir algo piensas «esto le pasará también al siguiente cliente», estás en el repo
equivocado.
