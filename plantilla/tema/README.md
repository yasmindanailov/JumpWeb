# `tema/` — la marca de esta instalación

Aquí van `client.css` (los tokens del tema), el logotipo, el icono de pestaña y el kit de símbolos. Es lo
que `docs/INSTALACION-CLIENTE.md` del producto llama «el paquete de tema».

⚠️ **Tokens, no reglas.** El producto pinta con variables CSS; lo que se escribe aquí son sus valores. Una
regla nueva de maquetación en `client.css` se salta la capa de tema y se rompe en la siguiente versión del
producto.
